### 🛠️ L'ARCHITECTURE ACTUELLE
Mon projet est une application FastAPI qui fusionne plusieurs couches d'intelligence :
1. **Mémoire Hybride** : Nous utilisons `ChromaDB` pour la mémoire vectorielle (RAG) et `NetworkX` pour un **Graphe de Neurones** (`core/graph.py`). Le cerveau connecte les concepts entre eux automatiquement.

3. **Serveur MCP (Model Context Protocol)** : Nous avons créé un serveur (`mcp_server.py`) qui expose des outils à mon assistant VS Code :

   - `generate_realistic_image` : Génération d'images ultra-réalistes via Flux.
